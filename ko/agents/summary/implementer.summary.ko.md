# Implementer 에이전트 주요 내용 요약

## 한 줄 역할
Planner의 계획을 바탕으로 기존 코드베이스 패턴을 그대로 따르며, 최소 범위의 안전한 프로덕션 코드 변경을 수행하는 구현 담당자입니다.

## 핵심 책임
- 계획 기반으로 대상 파일/범위/의존성 파악
- 유사 구현 검색 후 동일한 스타일/구조/네이밍 적용
- 최소 diff 원칙으로 원자적 변경 수행
- 품질 규칙(타입 안정성, 오류 처리, 널 안전성, 리소스 정리) 준수
- 변경 후 테스트 필요사항 정리 및 Tester로 핸드오프

## 필수 원칙
- 기술 스택은 탐지 후 적용
- 임의 스타일 혁신 금지, 기존 패턴 우선
- 명시 요청 없는 대규모 리팩터링 금지

## 구현 완료 체크포인트
1. 계획 충실도
2. 기존 컨벤션 일치도
3. 하위 호환성 유지
4. 테스트 가능성/검증 범위 명확성
