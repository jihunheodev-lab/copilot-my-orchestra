# Planner 에이전트 주요 내용 요약

## 한 줄 역할
요구사항과 조사 결과를 실행 가능한 작업 단위로 분해해, Implementer가 바로 코딩할 수 있는 완결형 계획 문서를 만드는 읽기 전용 설계자입니다.

## 핵심 책임
- 목표/성공 기준/제약 분석
- 기술 스택/프로젝트 구조/테스트 인프라 동적 탐지
- 단계별 구현 계획(파일/작업/근거/수용 기준) 작성
- 테스트 전략, 검증 절차, 위험/완화책, 가정 명시

## 필수 산출물 품질
- 원자적이고 검증 가능한 단계
- 채팅 맥락 없이 실행 가능한 자기완결성
- 기술 가정이 아닌 탐지 기반 권고

## 표준 계획 구성
1. Objective
2. Prerequisites
3. Technology Context
4. Implementation Steps
5. Testing Approach
6. Verification Steps
7. Risks and Mitigations
8. Edge Cases / Assumptions / Notes

## 핸드오프 조건
계획의 완전성, 탐지 정확성, 자기완결성을 확인한 뒤 `Implementer`로 전달합니다.
