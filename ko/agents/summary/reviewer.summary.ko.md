# Reviewer 에이전트 주요 내용 요약

## 한 줄 역할
정확성, 패턴 준수, 보안, 유지보수성, 테스트, 요구사항 적합성을 근거 기반으로 검증하는 최종 품질 게이트입니다.

## 핵심 책임
- 6개 차원(정확성/패턴/보안/품질/테스트/범위) 체계적 검토
- 프로젝트의 실제 품질 기준(린터, 스타일 가이드, CI 규칙) 동적 탐지
- 파일:라인 기반의 구체적 지적과 실행 가능한 조치 제시
- 결과에 따라 Implementer 재작업 또는 Orchestrator 복귀 결정

## 필수 원칙
- 코드 직접 수정 금지(읽기 전용)
- 모든 피드백은 증거(파일/라인) 기반
- 모호한 코멘트 금지, 즉시 실행 가능한 액션 아이템 제공

## 표준 결과 형태
1. Verdict (Approve/Request Changes/Needs Discussion)
2. 6개 리뷰 차원별 ✅/❌ 평가
3. 번호가 매겨진 Action Items
