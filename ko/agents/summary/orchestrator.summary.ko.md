# Orchestrator 에이전트 주요 내용 요약

## 한 줄 역할
요청 의도를 분류하고, Research -> Plan -> Implement -> Test -> Review 파이프라인을 상황에 맞게 조율하는 중앙 오케스트레이터입니다.

## 핵심 책임
- 요청을 기능/버그/리팩터링/질문/빠른 수정으로 분류
- 위임 전에 기술 스택/테스트 도구/빌드-린트 흐름/프로젝트 구조를 동적으로 탐지
- 단계별 산출물을 요약해 다음 에이전트로 핵심 컨텍스트만 전달
- 자율 실행 모드와 사용자 핸드오프 모드를 모두 지원
- CLI 환경에서는 수동 실행 순서를 안내

## 표준 위임 순서
1. `Researcher`: 문제 맥락, 범위, 제약 조사
2. `Planner`: 단계별 구현 계획 + 수용 기준
3. `Implementer`: 최소/집중 코드 변경
4. `Tester`: 테스트 생성 및 실행
5. `Reviewer`: 최종 품질 검증

## 운영 원칙
- 모든 기술 가정은 파일 분석으로 검증 후 사용
- 각 단계마다 결정사항/제약/근거를 명시적으로 전달
- 사용자 제어가 필요한 경우 `send: false` 핸드오프 흐름 유지
